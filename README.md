# HDL-Codes

This repository contains my **Verilog** and **SystemVerilog** practice codes, written to strengthen my understanding of **RTL design**, **HDL syntax**, and **verification concepts**.  
It includes basic design modules, testbenches, and SystemVerilog concept-based exercises.

---

## 📂 Repository Structure

### 🔸 [HDL-BITS](https://github.com/vignesh-rtl/HDL-Codes/tree/main/HDL-BITS)
Solved HDLBits Verilog exercises and assignments.

### 🔸 [SV VERIFICATIONS](https://github.com/vignesh-rtl/HDL-Codes/tree/main/SV%20VERIFICATIONS)
Small verification projects — DFF, SRAM, counter, etc.

### 🔸 [SYSTEM VERILOG](https://github.com/vignesh-rtl/HDL-Codes/tree/main/SYSTEM%20VERILOG)
Practice files for SystemVerilog concepts and OOP.

### 🔸 [VERILOG](https://github.com/vignesh-rtl/HDL-Codes/tree/main/VERILOG)
Verilog RTL design practice modules and testbenches.
